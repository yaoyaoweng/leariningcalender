課程行事曆產生器（PWA）安裝說明
====================================

【第一次上傳到 GitHub】
1. 登入 github.com（沒有帳號先按 Sign up 註冊，使用者名稱會變成網址的一部分）。
2. 右上角「＋」→ New repository → Repository name 填：course-calendar → 選 Public → Create repository。
3. 在新的 repository 頁面點「uploading an existing file」，
   把「課程行事曆_PWA」資料夾「裡面」的所有檔案和 icons 資料夾拖進去（不要拖整個外層資料夾）。
4. 拉到最下面按 Commit changes。完成後首頁要直接看到 index.html；如果只看到一個資料夾，代表拖錯層了。
5. 到 Settings → 左邊 Pages → Branch 選 main、資料夾選 / (root) → Save。
6. 等 1～3 分鐘，網址是：https://你的帳號.github.io/course-calendar/

【安裝到手機】
- iPhone：用 Safari 打開網址 → 下方「分享」→「加入主畫面」。
- Android：用 Chrome 打開網址 → 右上選單 →「安裝應用程式」或「加到主畫面」。

【第一次使用】
1. 按右上「設定」，輸入主持名單、主場名單。
2. 選月份，在課程表填課程，資料會自動存在這台裝置。
3.「LINE 通知」分頁可以一鍵複製隔天的通知文字。

【每晚 8 點提醒】
App 不能自己在晚上跳通知，請在手機設定重複提醒：
- iPhone：「提醒事項」新增一則，時間設 20:00、重複「每天」，內容寫「打開課程行事曆，複製明天的 LINE 通知」。
- Android：「時鐘」或 Google 日曆新增每天 20:00 的提醒。

【更新 App】
1. 進同一個 repository → Add file → Upload files。
2. 拖入新版資料夾裡的所有檔案（同名會覆蓋）→ Commit changes。
3. 等 1～2 分鐘，把手機上的 App 關掉再重開兩次就會更新。
   有換 icon 的話，iPhone 要先刪掉 App，再重新「加入主畫面」。

【注意】
- 資料只存在各自的手機或電腦裡，不會同步到別台裝置，也不會同步到 claude.ai 上的版本。
- 換手機或交接前，請先在「設定」按「匯出備份」，到新裝置再「匯入備份」。
- repository 是公開的，程式碼任何人都看得到，但你填的課程資料只存在自己的裝置，不會上傳。
